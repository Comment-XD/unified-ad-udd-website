Staged Multi-Modal Alzheimer Classification using Uncertainty Quantification

Balancing Diagnostic Accuracy and Clinical Resource Efficiency through Uncertainty Quantification.

Final Report PDF GitHub Presentation Video

Authors & Method

Methodology Summary

The core methodology utilizes an uncertainty-gated escalation framework to optimize the diagnostic pipeline for Alzheimer's Disease. The process begins with multi-modal feature alignment, synchronizing patient-level predictions and uncertainty scores across Clinical, MRI, and PET datasets. We implemented a dual-threshold selection strategy (tau1, tau2) that acts as a sequential decision gate; the system only escalates to higher-cost modalities such as MRI or PET when the prediction uncertainty of the preceding stage exceeds a mathematically optimized threshold. By applying vectorized decision logic to simulate thousands of diagnostic trajectories, we identified an optimal operating point that balances classification accuracy with resource utilization. This approach ensures that 60% of cases in the CN vs AD task are resolved using only primary or secondary modalities, significantly reducing clinical burden without compromising diagnostic integrity.
